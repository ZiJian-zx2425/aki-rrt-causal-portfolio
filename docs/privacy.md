# Privacy and release boundary

## Included

New prose describing general methods; independently written synthetic demonstration code; diagrams made from shapes and text; tests; environment specifications; aggregate outputs from the declared synthetic generator.

## Excluded

Patient records, restricted EHR extracts, real identifiers, patient-level dates, rare clinical summaries, institution-specific paths, credentials, original notebooks and their outputs, source archives, clinical model weights, original report/slides, and clinical study estimates. No source archive was extracted into the public repository. No patient data were read by the demonstration.

## Review procedure

1. Author in a fresh directory rather than publishing an existing research checkout or its history.
2. Inspect every release file and every image. Verify that numerical outputs are generated by `rrt_demo.synthetic` rather than copied from a study.
3. Search text for credentials, local/server paths, identifiers, and unintended data artifacts. Confirm image contents visually and remove external image links or embedded source metadata where present.
4. Generate `release-manifest.json` containing the SHA-256 of each reviewed release file. Include only those files and the manifest in publication.
5. Run `python scripts/check_release.py` immediately before upload. Changes require a new human/agent review and manifest update; a checksum alone is not a safety judgment.
6. Verify the remote file list and public visibility after upload. Do not push any private working directory or inherited research Git history.

The ignore file reduces accidental staging but is not a privacy guarantee. Local audit notes outside this repository are not part of the release. Future clinical content needs a separate provenance and disclosure review, even if it contains only aggregate results.

## Contributions and reuse

Do not submit patient records, real case examples, institutional data, credentials, or trained clinical models in issues or pull requests. Describe bugs using the synthetic generator. No license to original institutional research materials is granted. This initial release does not select a blanket redistribution license; a public GitHub repository is not automatically an open-source license.
